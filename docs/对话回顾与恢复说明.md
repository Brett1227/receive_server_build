## 三、本次对话（分享链接）最后遗留的问题

对话末尾在排查「WorkBuddy 侧边栏项目空白」的问题，结论如下（对以后维护有参考价值）：

1. **文件从未丢失**：`C:\Users\Brett\WorkBuddy\receive_server_build\` 磁盘内容完整。
2. **根因**：WorkBuddy 侧边栏「项目」读取的是 `~/.workbuddy/workbuddy.db` 的 `workspaces` 表；
   之前程序化写入的记录用了**正斜杠**路径（`C:/...`），而侧边栏只认**反斜杠**（`C:\...`），导致静默不显示。
3. **运行中的 app 会守护该表**：只要 WorkBuddy 开着，脚本改 DB 会被 app 实时回写覆盖，程序化修改无效。
4. **可靠解法**：在 WorkBuddy 左侧「项目」区使用 **「打开文件夹」**，手动选择
   `C:\Users\Brett\WorkBuddy\receive_server_build`，由 app 自身注册（反斜杠格式），即可显示并持久化。

## 四、后续维护指引

- **改功能**：编辑 `source/receive_server_v1.0.py` → 用打包环境重新打包（见 README「打包环境」）→ 替换 exe。
- **打包前**：务必先确认无 `receive_server.exe` 进程在运行（否则新 exe 无法覆盖旧文件）。
- **加新需求**：建议先在 `requirements_prompt.md` 追加需求章节，再改代码，保持文档与代码同步。
- **部署**：只需拷 `receive_server_v1.0.exe` + `使用说明.txt` 到主机，双击运行。
