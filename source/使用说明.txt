========================================
  扫码直连 · 文件传输到打印机主机
  （无需联网 · Windows 电脑专用）
========================================

一、这套东西是什么？
--------------------
打印机主机（Windows，不联网）上运行一个接收程序。
启动后电脑屏幕弹出二维码窗口（没有黑命令行窗口），
前来打印的同事用手机连上电脑的 WiFi 热点，
扫屏幕上的二维码即可把文件传到电脑的保存目录，
之后自行打印，无需其他操作。
全程局域网直连，不经过互联网。

文件说明（拷到主机任意文件夹即可）：
  receive_server.exe   接收程序（已打包，无需安装 Python）

二、需要准备
------------
1. 电脑要有无线网卡（能开热点就行，不需要联网）
2. 不需要安装 Python
3. 同事手机支持扫码即可

三、使用步骤（每次开机后）
--------------------------
第 1 步：打开电脑的移动热点
  设置 → 网络和Internet → 移动热点 → 打开开关
  热点名称设置为：打印机主机连接
  热点密码设置为：73556088（与窗口显示的提示一致），
  方便同事直接看窗口输密码。

第 2 步：启动接收程序
  双击 receive_server.exe，弹出二维码窗口：
  - WiFi 热点名称：打印机主机连接（深色字）
  - WiFi 热点密码：73556088（橙色大字，直接告诉同事）
  - 大二维码：同事扫码直接进入上传页面
  - 上传地址：手机也可手动输入这个地址
  - 保存目录：显示当前文件保存位置，旁边有【修改…】按钮
  - 已接收文件：实时显示收到的文件，点击文件名可打开
  - 打开上传记录：查看上传人、部门、时间的统计表格
  程序窗口请保持打开，别关。

第 3 步：同事传文件（手机操作）
  手机连接电脑的移动热点（密码 73556088）→
  扫电脑屏幕上的二维码 → 进入上传页面 →
  填写【上传人部门】【上传人姓名】（必填）→
  选择文件 → 点【开始上传】→ 手机提示"上传成功"。
  文件保存到电脑指定目录，并自动弹出该文件夹，
  同事自行打印即可。可一次选择多个文件批量上传。
  * 不填部门、姓名无法上传，会提示先填写。

  * 微信里收到的文件传不上来？
    微信的文件存在手机私有空间，要先"保存"再上传。
    上传页面顶部有蓝色提示条，点开有详细步骤：
    Android 文档：微信点开文件 → 右上角··· → 点【保存】
        → 回本页选文件时在"最近/下载"里就能看到
    iPhone 文档：微信点开文件 → 右上角··· → 用其他应用打开
        → 存储到"文件" → 选位置点存储
        （若当前位置是 iCloud 云盘，先点"浏览"，在位置里选
          "我的 iPhone"，再存储，这样才存到手机本地）
        → 回本页选文件时进"文件"里刚保存的位置
    图片：微信长按图片 → 保存到相册 → 上传时选相册

四、上传记录表格（管理员查询）
------------------------------
每次上传都会自动记录到 exe 旁边的"上传记录.xlsx"，
用 Excel 打开即可查询，可按部门/姓名/时间筛选：
  上传时间 | 部门 | 姓名 | 文件名 | 保存路径
窗口里点【打开上传记录】按钮可一键打开表格。
文件本身保存在保存目录，形成"文件 + 记录"双备份。

五、主机窗口说明
----------------
  窗口里"已接收文件"列表只显示收到的文件，
  点击文件名可直接打开该文件。
  收到文件后会自动打开保存文件夹，方便直接拿去打印。
  点"保存目录"旁边的【修改…】按钮可更改保存位置，
  修改后自动记住，下次启动仍用这个目录。
  （首次运行默认保存在 exe 旁边的 received 文件夹）

六、常见问题
------------
Q：同事扫屏幕二维码打不开页面？
A：先确认手机已连接电脑的移动热点，且热点开关是打开的。

Q：二维码扫了但打不开，提示无法访问？
A：多数是热点没开，或手机连的不是这个热点。个别电脑
   的移动热点网段不同，请在二维码窗口里看"上传地址"，
   让同事用浏览器手动输入那个地址。

Q：怎么开机自动启动接收程序？
A：把 receive_server.exe 的快捷方式放进启动文件夹：
   按 Win+R，输入 shell:startup 回车，把快捷方式拖进去。
   注意：热点仍需手动打开（或到设置里把移动热点设为
   "自动开启"）。

Q：文件会覆盖同名旧文件吗？
A：不会。同名文件会自动保存为"xxx (1).pdf"。

Q：能传多大的文件？
A：单文件上限 500MB，日常文档、图片、PDF 都足够。

Q：双击 exe 没反应？
A：等几秒（首次启动需要自解压）。若防火墙弹窗询问，
   请允许"专用网络"访问——否则手机连不上服务。
   如果弹出"启动失败"提示，多半是程序已经在运行了，
   关掉旧的再开即可。

六、安全说明
------------
- 传输全程在电脑和手机之间的 WiFi 直连通道内完成，
  不经过互联网，符合隔离环境要求。
- 热点密码建议定期更换，防止无关设备连入。
- 收到文件后，建议在电脑上杀毒软件扫描后再打开。
